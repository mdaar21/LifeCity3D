# Original assets and dependency licenses

LifeCity icon family (SVG/PNG), procedural city/interior geometry, garden SVG
compositions and application code were authored for this project. No copied
commercial game models, existing game UI, stock photos, music or external HDR
maps are used. The proposed product name has **not** been trademark-cleared.

Arabic typography: Tajawal Regular/Bold from Google Fonts, SIL Open Font License
1.1. Full license: `public/fonts/OFL.txt`. Download source:
https://github.com/google/fonts/tree/main/ofl/tajawal . Keep font copyright and
license notices with redistributions. UI pictograms: Lucide, ISC license.

Resolved direct production-dependency versions and declared license IDs are in
`docs/evidence/direct-dependencies.json`. Checked direct packages are MIT, ISC
or Apache-2.0. PGlite itself declares Apache-2.0 and embeds PostgreSQL components
with their applicable notices. Do not remove node_modules/package notices from
distributed dependencies. This inventory is a direct-dependency review, **not
a legal certification of all transitive software or provider terms**.

`npm audit --omit=dev` was actually run; final recorded counts belong in the
release report. Security advisories and licensing are separate checks. An audit
with zero reported advisories is not a promise that software has no bugs.

Supabase, GitHub and Netlify service use remains subject to the account holder's
actual provider terms. No paid provider plan, domain registration or service
subscription has been purchased in this implementation.
