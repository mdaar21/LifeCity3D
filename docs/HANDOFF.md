## المكتمل والقرارات الثابتة

- React/Vite/TypeScript، مدينة R3F فعلية، متجر ومخزون وبناء يدوي وأثاث داخلي،
  المهام والدراسة والصلوات ودفتر العملات، ويوي بصلاحيات مستقلة، العربية والإنجليزية وPWA.
- إضافات المستخدم المكتملة:1 دليل أول مهمة/شجرة/تثبيت يدوي؛2 ادخار مبنى
  بمساهمات واسترداد موثّق وإضافة للمخزون عند الاكتمال؛4 نبتة تركيز تنمو
  بالدقائق المعتمدة؛5 روابط زيارة خارجية محدودة وقابلة للإلغاء وتفاعلات للحسابات.
- المستخدم ألغى إضافة3: لا سكان أو سيارات متحركة تلقائيًا، ولا وضع مبانٍ تلقائيًا.
- القالب starter-web-app-template مضاف كمرجع Git اختياري مثبت فقط، مع الحفاظ
  على بناء LifeCity. اقرأ starter-template-integration.md؛ لا تشغّل نصوص تهيئته.
- آخر تحقق محلي:41 اختبارًا ضمن11 ملفًا،6 مسارات متصفح،22 حالة وصول آلي
  دون مخالفات مكتشفة و20 حالة عرض دون تجاوز أفقي. الأدلة في evidence/ وrelease.md.

## المتبقي: الحسابات السحابية

- الموقع المنشور حاليًا تجربة ضيف محفوظة في متصفح واحد، وليس حسابات سحابية مفعّلة.
- مشروع Supabase الذي حدده المستخدم:
  https://taevxcuqsanfyywkuygl.supabase.co
- فحص سابق بالمفتاح العام نجح لإعدادات Auth، لكن game_state أعاد PGRST202/404.
- المستخدم شغّل ملف تجهيز القاعدة وظهر:
  ERROR42P07: relation "profiles" already exists.
- بنية الجداول الموجودة لم تُفحص بعد. لا تحذف profiles أو تعِد تشغيل الإنشاء
  الكامل أو تتجاوز التعارض عميانيًا. افحص الجداول والأعمدة والدوال وRLS أولًا،
  وحدد هل هي نسخة LifeCity جزئية أم بيانات مشروع آخر، ثم حضّر ترحيلًا يحفظ البيانات.
- ملفات الترحيل المطلوبة في supabase/migrations/001..006، ثم supabase/seed.sql.
- أداة إدارة Supabase لم تكن متاحة في هذه المحادثة رغم محاولة المستخدم ربطها.
  افحص أدوات المحادثة الجديدة؛ لا تفترض توفر اتصال أو صلاحية من سياق قديم.
- ظهر مفتاح سري في المحادثة السابقة؛ لا تعِد نسخه أو تخزينه. لم يُتحقق من تدويره.
  تحتاج مفاتيح المتصفح العامة فقط للبناء؛ إدارة SQL تحتاج اتصالًا إداريًا مصرحًا.
- لا تفعّل وضع supabase في البناء إلا بعد تجهيز القاعدة واختبار الحسابات.
  إعدادات البناء: VITE_BACKEND_MODE، VITE_SUPABASE_URL، VITE_SUPABASE_ANON_KEY.
  كان اتصال GitHub يرفض إدارة Actions variables؛ قد يلزم ضبطها من لوحة المالك.
