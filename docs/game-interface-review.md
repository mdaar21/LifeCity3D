# متابعة واجهة اللعب — LifeCity 3D

هذه متابعة للمشروع الموجود، لا إعادة إنشاء له. صفحات البداية والدخول احتفظت
بتصميمها، والدخول الافتراضي أصبح `/city`، مع بقاء `/dashboard` كسجل رحلة.

## المكتمل

| الجزء | السلوك الحالي |
|---|---|
| تجربة اللعب | مدينة WebGL تملأ الشاشة، وHUD دائم للعملات ومستوى اللاعب وحالة الحفظ |
| التنقل | شريط المدينة والمهام والتركيز والمتجر؛ بقية الأقسام في قائمة لعبة مستقلة |
| الأقسام | نوافذ قابلة للتمرير داخل اللعبة، إغلاق إلى المدينة وEscape، عنوان واضح لكل نافذة |
| المهام | قائمة مهمات مختصرة، مكافأة وحالة وحد تكرار، مع إنشاء وتعديل وأرشفة المهام الحالية |
| المتجر | العناصر والبحث والفئات والمعاينة والشراء في قسم، ومشاريع الادخار في قسم منفصل |
| البناء | مخزون ومعاينة وتثبيت وتدوير ونقل وإزالة وتوسعة، مع لوحة منفصلة للعناصر والزيارات |
| التركيز | متابعة واحدة للجلسة طوال اللعب، حتى أثناء فتح المهام والمتجر؛ المؤقت المعروض لا يمنح عملات |
| استمرارية العالم | نفس canvas والكاميرا أثناء التنقل العادي بين القوائم؛ التأثيث عالم مستقل كما كان |
| الوصول واللغة | العربية والإنجليزية وRTL/LTR، لوحة مفاتيح، حبس التركيز داخل قائمة اللعبة وإعادته عند الإغلاق |
| ما حُفظ | واجهات RPC والرصيد والدفتر والمهام والمخزون والمشاريع والزيارات وقواعد البناء الحالية |

لا تغيير في الجداول أو بيانات اللاعبين، ولا سكان/سيارات أو وضع مبانٍ تلقائي.
التنقل الجديد يستجيب لطلب المالك الأحدث بقوائم ألعاب بدل الشريط الجانبي السابق.

## التحقق المنفذ

- تثبيت المكتبات بنجاح عبر `npm ci --no-audit --no-fund` مع ملف القفل الموجود.
- `npm run lint` و`npm run typecheck` نجحا.
- `npm test`: **43 اختبارًا في 12 ملفًا**، وتشمل دورة متابعة المؤقت والتوقف
  والاتصال ومنع الطلبات المتراكبة والتعافي من فشل الطلب.
- مسارات المتصفح الثمانية نُفذت على دفعات: الضيف والتسجيل، البناء/مشاريع
  الادخار، الزيارات وإلغاؤها، مطابقة المدينة بين متصفحين، عزل الحسابات،
  استمرارية canvas والملاحة بلوحة المفاتيح، ومراجعة HUD والقوائم.
- فحص WCAG آلي لتسع حالات: المدينة والمهام والمتجر والمؤقت بعرض1440 و390،
  والمهام بالإنجليزية والوضع الداكن. لا مخالفات مكتشفة أو تجاوز أفقي في هذه الحالات.
  الفحص ينتظر انتهاء حركة فتح النافذة قبل قياس تباين الألوان.
- بناء الإنتاج و`build:github` نجحا. محاكاة المسار `/LifeCity3D/` وPWA نجحت:
  تحميل بارد للمدينة، عدم تحميل Three في صفحة الدخول، Service Worker فعلي،
  استعادة الرصيد المحفوظ دون اتصال، تعطيل العمليات المالية، وحفظ/استرداد مشروع.
- لا قياس FPS على هاتف فعلي، ولا ادعاء بفحص يدوي على كل الأجهزة.

## المتبقي خارجيًا

فحص Supabase الإداري للقراءة فقط أكد المخطط ودوال اللعبة والكتالوج وRLS؛
راجع [نتيجة الفحص وحدودها](evidence/supabase-inspection-2026-10-30.json).
وجود الدوال لا يثبت جاهزية Auth أو البريد أو حفظ الحساب بين أجهزة حقيقية.
لم نغيّر وضع النسخة المنشورة من ضيف إلى سحابي، أو نشغّل ترحيلات إنشاء متعارضة.

قبل تفعيل الحسابات: راجع إعدادات Auth وروابط العودة ومسار GitHub Pages، واضبط
متغيرات بناء Supabase العامة، ثم اختبر التسجيل وتأكيد البريد والاستعادة وحفظ
مدينة فعلية للحساب نفسه في متصفحين مستقلين. لا تستخدم مفتاحًا سريًا في VITE_.

التحديث على فرع مراجعة في GitHub؛ الموقع الحالي لا يتغير قبل الدمج والنشر الناجح.
